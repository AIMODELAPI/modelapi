怎么「调用这个端口」

兼容 OpenAI SDK。把 base_url 换成 ModelAPI，其余代码一行不动。

# Python
from openai import OpenAI
client = OpenAI(
  base_url="https://api.modelapi.ai/v1",
  api_key="YOUR_MODELAPI_KEY"
)
resp = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[{"role":"user","content":"你好"}]
)
