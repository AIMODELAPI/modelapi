API Access Beta
Programmatic access to ModelAPI generation endpoints.
Endpoints
POST/api/image
Generate an image from a text prompt. Sizes: 1024x1024 / 1280x720 / 720x1280. Cost: 10 credits per image.
curl -X POST https://www.aimodelapi.top/api/image \ -H "Content-Type: application/json" \ -d '{"prompt":"a lighthouse at dusk, cinematic","size":"1024x1024","n":1}'
POST/api/video
Submit a video generation task (async). Duration: 3 / 5 / 10 s. Resolution: 720P (25 credits/s) or 1080P (35 credits/s).
curl -X POST https://www.aimodelapi.top/api/video \ -H "Content-Type: application/json" \ -d '{"prompt":"waves crashing on a rocky shore","duration":5,"resolution":"720P"}'
GET/api/video?task_id={id}
Poll a video task until status becomes "succeeded" and a video_url is returned.
curl "https://www.aimodelapi.top/api/video?task_id=TASK_ID"

⚠️ API access currently shares your web account's credit pool. Authenticated per-account API keys are on the roadmap — contact aimodelapi@163.com if you need early access.
