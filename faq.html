1. ModelAPI란?

ModelAPI는 멀티모델 AI 오케스트레이션 플랫폼(AI 인프라 SaaS)입니다. OpenAI 호환 엔드포인트 하나로 100개 이상의 AI 모델을 실행할 수 있어, 공급자 연결 대신 구축에 집중할 수 있습니다.

2. What does an AI orchestration platform mean?

It means one platform handles model scheduling, routing, usage tracking, and billing for you. You call a single endpoint; the platform orchestrates the rest.

2. 什么是 AI 编排平台？

意思是：一个平台帮你统一处理模型调度、路由、用量追踪和计费。你只管调用一个端点，剩下的调度工作全交给平台。

2. AIオーケストレーションプラットフォームとは？

1つのプラットフォームがモデルのスケジューリング、ルーティング、使用量追跡、請求を担当することを意味します。単一のエンドポイントを呼び出すだけで、残りはプラットフォームがオーケストレーションします。

2. AI 오케스트레이션 플랫폼이란?

하나의 플랫폼에서 모델 스케줄링, 라우팅, 사용량 추적, 청구를 처리한다는 뜻입니다. 단일 엔드포인트를 호출하면 나머지는 플랫폼이 오케스트레이션합니다.

3. How is ModelAPI different from a simple API forwarder?

ModelAPI is a software platform (SaaS). We provide orchestration, routing, and unified billing. We are not a middleman layer — we are the infrastructure that lets model providers work for you.

3. ModelAPI 和单纯的接口转发有什么区别？

ModelAPI 是一个软件平台（SaaS），提供编排、路由与统一账单能力。我们不是中间商层——我们是让模型供应商直接为你工作的基础设施。

3. ModelAPIは単なるAPI転送とどう違いますか？

ModelAPIはソフトウェアプラットフォーム（SaaS）です。オーケストレーション、ルーティング、統一請求の機能を提供します。私たちは中間層ではありません——モデルプロバイダーがあなたのために働くインフラです。

3. ModelAPI는 단순한 API 전송과 어떻게 다른가요?

ModelAPI는 소프트웨어 플랫폼(SaaS)입니다. 오케스트레이션, 라우팅, 통합 청구 기능을 제공합니다. 우리는 중간 계층이 아닙니다 — 모델 공급자가 당신을 위해 일하는 인프라입니다.
